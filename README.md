# 🎉 Evently – Event Management App

Evently is a Flutter mobile application designed to help users discover, organize, and manage events through a simple and user-friendly interface. The app integrates Firebase to provide authentication and cloud data storage, making event management smooth and efficient.

## ✨ Features

* **User Authentication:** Sign up and log in using Firebase Authentication.
* **Create Events:** Add new events with a title, description, date, time, category, and image.
* **Browse Events:** Display events in an organized and visually appealing layout.
* **Category Filtering:** Filter events by category, such as Sports and Birthdays.
* **Event Details:** View detailed information about each event.
* **Favorites:** Mark events as favorites for quick access.
* **Cloud Database:** Store and retrieve event data using Cloud Firestore.
* **Real-Time Updates:** Display updated event data using Firestore streams.
* **User-Friendly Interface:** Clean UI with reusable Flutter widgets.

## 🛠️ Technologies Used

* **Flutter** – Cross-platform mobile application development.
* **Dart** – Programming language.
* **Firebase Authentication** – User registration and login.
* **Cloud Firestore** – Cloud database for storing and retrieving events.
* **Material Design** – Building a consistent and responsive user interface.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Visual Studio Code or Android Studio
* A Firebase project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rawda11-Mohamed/evently.git
   ```

2. Navigate to the project directory:

   ```bash
   cd evently
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your application using the Firebase Console and FlutterFire CLI, if required.

5. Run the application:

   ```bash
   flutter run
   ```
